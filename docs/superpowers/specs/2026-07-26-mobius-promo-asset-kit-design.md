# Mobius 宣传片素材库设计

日期：2026-07-26
状态：已确认，进入制作

## 1. 目标

为《Mobius 宣传视频逐镜头优化稿》制作一套可直接用于剪辑、合成、网页和演示文稿的统一品牌素材。现有 `mobius-ring-standalone.html` 继续作为环形轨迹动画，不重复开发；本素材库补齐 Logo、七项能力、人类与智能体节点、设备外框、模型与算力资源图标，以及关系动画配件。

## 2. 已确认方向

- 同时提供深色与浅色背景版本。
- 采用“系统线框＋品牌能量轨迹”：基础轮廓克制，激活状态使用 Mobius 青—蓝—紫—粉渐变。
- Logo 采用双轨交付：几何矢量主标用于动画与无限缩放；高分辨率透明质感版用于揭示镜头、片尾和封面。
- 不使用机器人头、Emoji、3D 拟物、扳手或锤子等通用 AI／工具平台符号。
- 图标最终必须服务真实产品录屏，不替代真实 UI。

## 3. 视觉系统

### 3.1 色彩

品牌渐变沿用现有 Mobius 环动画：

- Cyan：`#22D3EE`
- Sky：`#7DD3FC`
- Violet：`#8B5CF6`
- Lavender：`#A78BFA`
- Magenta：`#EC4899`
- Pink：`#F472B6`

主题色：

- 深色画布：`#030014`
- 深色主线：`#E6EEFF`
- 深色辅线：`#64748B`
- 浅色画布：`#F7F9FF`
- 浅色主线：`#17213A`
- 浅色辅线：`#8090AA`

### 3.2 造型

- 图标母版使用 `96×96` 网格，主线宽 3，辅线宽 2，全部采用圆角端点与圆角连接。
- 默认态为单色结构图；激活态把关键路径替换为品牌渐变并增加克制的外发光。
- 人类节点为圆形；智能体节点为圆角方形或六边形，两者一眼可辨。
- SVG 的背景保持透明；深浅主题只改变轮廓与发光参数。
- 每个 SVG 使用稳定、语义化的分组 ID，方便后期逐层动画。

## 4. 素材范围

### 4.1 Logo

- 彩色几何矢量主标。
- 纯白、深色、单色品牌渐变矢量版本。
- 透明背景高分辨率品牌质感 PNG，最大宽度 4096px。

### 4.2 七项能力

1. 持续自进化：Mobius 轨迹长出新节点与界面模块。
2. 智能小莫：星芒核心与自然语言气泡。
3. 复杂项目团队协作开发：项目卡片连接人类成员和任务状态。
4. 多智能体编队：任务核心连接多个六边形智能体节点。
5. 多端协同：Web、PC、手机由连续任务轨迹贯穿。
6. 连接一切并调度资源：调度核心连接模型、服务器、GPU 与设备。
7. 按需孵化拓展：空白拓展框生成界面、数据与连接端口。

每项能力提供默认态／激活态、深色／浅色四种组合。

### 4.3 人类与智能体

- 4 个可区分的人类矢量头像＋1 个中性剪影。
- 6 个智能体核心符号：星芒、终端、代码、浏览器、研究、规划。
- 圆角方形与六边形两种节点容器。
- 默认、运行中、已完成、异常四种独立状态配件。

### 4.4 设备与资源

- Web 浏览器、PC／笔记本、手机设备框，各有空白屏与示例屏。
- 通用模型、推理模型、云服务器、机架服务器、GPU、工作站、本地 PC、浏览器测试设备。
- 连接线、运行光点、任务卡、状态标签与调度路径配件。

## 5. 交付格式

根目录：`docs/superpowers/assets/mobius-promo-kit/`

- 可编辑 SVG 源文件。
- 透明 PNG 导出：图标 1024px；设备长边 2160px；Logo 最大宽度 4096px。
- 3840×2160 深色／浅色总览与分类预览图。
- `manifest.json` 机器可读索引。
- 中文 `README.md` 与动画建议。
- 可重复运行的生成脚本和自动校验。

## 6. 动画原则

- 默认态到激活态的核心变化是“品牌光点沿路径运行并点亮关键结构”。
- 七项能力节点不得做七张卡片机械弹出的 PPT 动画；中心 Mobius 环始终作为关系母体。
- 人类协作用连接线依次亮起来表达；多智能体用任务从中心向外分发、结果再回流表达。
- 多端协同必须让同一任务轨迹穿过 Web、PC 与手机。
- 资源调度先出现任务需求，再高亮被选择的模型、设备和算力，最后回传结果。
- 尊重真实 UI：图形合成只用于解释连接关系、状态变化和局部强调。

## 7. 验收标准

- 所有 SVG 均可被 XML 解析，包含 `viewBox`、透明背景和语义分组。
- 文件名、主题、状态、类别与 `manifest.json` 一致。
- PNG 尺寸符合各类别导出规则且保留透明通道。
- 深浅主题预览中所有图标均有足够对比度，没有被裁切或明显重叠。
- Logo、能力图标、人物、智能体、设备和资源图标在视觉上属于同一系统。
- 素材包不包含 Token、账号、IP、客户数据或其他敏感信息。
