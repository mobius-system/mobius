# Mobius 宣传片素材动画指南

## 1. SVG 分层约定

所有 SVG 至少包含以下分组：

- `icon-structure`：稳定的主体结构。通常保持 100% 不透明，只做轻微缩放或描边揭示。
- `energy-trail`：品牌光轨、运行点和激活结构。默认态可以为 0% 不透明，激活时再出现。

不同分类还包含：

- Logo：`mobius-ribbon`
- 七项能力：`capability-symbol`
- 人物：`portrait`
- 智能体：`agent-core`
- 状态：`state-indicator`
- 设备：`device-screen`
- 资源：`resource-symbol`
- 连接配件：`relation-path`

导入软件若自动改写 ID，应以图层的相对层级识别，不要把 `energy-trail` 与主体合并。

## 2. 通用激活动画

建议时长为 16～22 帧（25fps）：

| 帧 | `icon-structure` | `energy-trail` | 节点效果 |
|---|---|---|---|
| 0 | 75% 辅线亮度 | 0% 不透明 | 100% 尺寸 |
| 4 | 85% 主线亮度 | 20% 不透明 | 101% 尺寸 |
| 10 | 100% 主线亮度 | Trim Paths 0%→75% | 104% 尺寸 |
| 16 | 100% | Trim Paths 100%，短暂发光 | 100% 尺寸 |
| 22 | 100% | 发光回落至 55% | 100% 尺寸 |

缩放必须克制，不能做弹性过强的卡通跳动。光点比轮廓稍快，在描边终点提前 1～2 帧到达。

## 3. Logo 揭示

对应分镜 02 的 00:26～00:28：

1. 一个 4～6px 光点从中心出现，保持约 4 帧。
2. 沿 `mobius-ribbon` 使用 Trim Paths 从 0% 绘制到 100%，时长约 20 帧。
3. 交叉前景段晚 3 帧出现，强化莫比乌斯带的前后关系。
4. `energy-trail` 光点沿轨迹完成约 0.8 圈，在 Logo 完整时停在右上区域。
5. 品牌质感粒子最后淡入，不与路径绘制同时爆发。
6. Logo 完整后至少停留 1 秒；片尾停留至少 2 秒。

## 4. 七项能力总览

- Mobius 环始终在中心，不随每项能力切换而消失。
- 能力节点沿环出现，前一项激活结束后保留为已连接状态，亮度回落到约 55%。
- 下一项节点由运行光点抵达后激活，不使用七张卡片依次从画外弹入。
- 七项能力全部形成后，运行光点继续完成一圈，再选择“持续自进化”进入真实案例。

## 5. 人类团队与多智能体

### 人类团队

- 圆形人物头像先出现，项目卡片后出现。
- 连接线从人物指向项目；连接亮起时再出现任务或反馈状态。
- 不给人物头像加持续呼吸光，避免把人类也表现成智能体。

### 多智能体编队

- 方形／六边形节点从任务核心向外形成。
- 任务分发：中心到节点，线条 0%→100%。
- 结果回传：节点到中心，使用方向相反的光点。
- 多节点同时运行时错开 3～5 帧，避免机械同步。

## 6. 多端协同

1. 在 Web 设备中显示项目与当前任务。
2. `relation-traveler` 光点离开 Web，沿连续路径进入 PC。
3. PC 内继续显示同一个任务的执行状态。
4. 光点再进入手机，手机显示进度、补充要求或确认操作。
5. 三个设备的项目名、任务名和状态必须一致，不能只摆放三张不同界面。

录屏放在 `device-screen` 下方，通过轨道遮罩或 Alpha Matte 限制在屏幕区域。设备框本身不做大幅透视旋转，以免真实 UI 难以辨认。

## 7. 模型、设备与算力调度

1. 任务卡先出现，资源全部保持默认态。
2. 任务需求关键词依次点亮，例如“推理”“GPU”“远程执行”。
3. 从任务卡向候选资源发出低亮度路径。
4. 被选择的模型、服务器、GPU 或设备切换到 `active` 版本；未选择项保持默认态。
5. 光点沿选中路径运动，资源节点显示 `running` 状态配件。
6. 完成后光点沿原路径回到任务卡，状态切换为 `complete`。

不要显示真实 IP、账号、密钥、服务器域名或私有网络信息。

## 8. 状态配件

- `state-node-dark/light`：未运行或待命。
- `state-node-running-*`：运行中；环形弧线可以持续旋转，但速度不高于每秒一圈。
- `state-node-complete-*`：已完成；只播放一次勾选描边。
- `state-node-error-*`：异常；短暂闪烁一次后保持，不做持续红色警报。

状态配件应作为独立图层覆盖在节点右下角，不要改动人物或智能体源文件。

## 9. 降低动态与静态替代

需要减少动态时：

- 保留从默认态到激活态的 8～12 帧淡入。
- 取消循环呼吸、无限旋转和持续闪烁。
- 运行光点只移动一次，随后停留在路径终点。
- 静帧优先使用激活态 PNG，不要截图动画中间的半透明帧。
