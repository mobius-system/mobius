用户隔离重构 · 设计方案

Agent 文件系统沙盒
详细实施方案

限制 mobius spawn 的 AI Agent 只能读写指定路径，防止跨用户访问。
本方案为纯 Landlock 黑名单方案：驱动已实现并逐项实测通过（见 §2）。

一句话：用一个 Python 脚本（ctypes 直调内核），在 Agent 启动前把「除其他用户工作路径外的一切」授予它，然后 exec。 宿主与容器通用、零构建、零特权；启动时自检内核能力，任何问题即回退到「不允许创建普通用户」。 代价是只能用内核给的 Permission denied。
定稿日期：2026-10-09 适用范围：mobius spawn 的全部 Agent（claude-code / codex / deepseek-harness）

1为什么是 Landlock（选型结论）

需求有三条硬约束：宿主机与 Docker 容器内都要能用、安装极简、按路径限制文件系统。三条约束逐一把其他方案排除：

方案宿主机默认 Docker 容器判定
bubblewrap
mount namespace 掩码		 需解锁 userns 需容器放权 黑名单最干净，但两处都要改系统配置，且无法自定义错误 → 排除
Sandlock
Landlock + seccomp 监督进程		 可用 连启动都失败 容器内 pidfd_getfd 被 Docker 默认策略拦死 → 排除
纯 Landlock 可用 实测通过，零放权 唯一同时满足两处、且零配置的方案 → 选定

1.1 关键实测证据

① Sandlock 在默认容器里根本起不来（连"只跑 echo"的对照组都失败）：

Error: process error: child process error:
       pidfd_getfd: Operation not permitted (os error 1)

定位结论：单独加 --security-opt seccomp=unconfined 即可救活，加 apparmor=unconfined 无效 ⇒ 元凶就是 Docker 默认的 seccomp 策略。

② 所有"监督进程类"方案在容器内全军覆没 —— 监督进程必须读取被测进程内存里的路径，而所有手段都被堵死：

读取手段默认容器内结果
pidfd_getfdOperation not permitted
/proc/<子进程>/memPermission denied（实测，父读子亦被拒）
process_vm_readv / ptraceDocker 默认策略拦截

③ Landlock 在默认容器内完全生效（只授权 alice、不给 bob）：

读 alice        → alice-data            ✅ 正常
读 bob          → Permission denied     ✅ 拦截
写 bob          → Permission denied     ✅ 拦截
建目录 in bob   → Permission denied     ✅ 拦截
列目录 bob      → Permission denied     ✅ 拦截
为什么不用 seccomp seccomp 的黑名单是清单式的 —— 只有列进清单的系统调用才会被拦截。实测 Sandlock 漏掉了 mkdirat / symlinkat / fchmodat，可被用于创建目录、软链、修改他人文件权限。 而 Landlock 按路径判定，不存在清单，天然没有这类缺口。

独立复验 —— 把 socket 放进被显式 deny 的目录里，同一次进程内自带对照：

$ ./mobius-landlock --policy p_bob.txt -- python3 -c "..."

分析：Landlock 拦 open，但不拦 connect。 Unix socket 连接不经过文件系统的权限判定 —— 目录被 deny、open 被拒，connect 依然成功。

推论：凡是"沙盒外的服务 + 可达的 unix socket"都是绕过通道。mobius 环境下至少三个： tmux server（已实测逃逸，且它正是 Agent 的宿主）、code-server（回环监听 + --auth none）、 docker.sock（可达即等价 root）。把 socket 挪到别处无效（connect 不看路径授权）， deny 列表也拦不住 —— 解决方案见 §9.2。

4沙盒实现

3.1 启动器（新建，单个 Python 脚本）

用 ctypes 直调内核（syscall 444 / 445 / 446），不需要编译、零第三方依赖。 一次编写，宿主与容器共用同一份文件 —— 两处都已有 python3： 本机 /usr/bin/python3；mobius 容器 mobius-system-base 内为 Python 3.11.2。

# 应用沙盒并执行目标命令
mobius-landlock --policy <策略文件> -- <命令> [参数...]

# 内核能力自检（mobius 启动时调用；详见 4.2）
mobius-landlock --check      # 退出码 0 = 可用；非 0 = 不可用
为什么是 Python 而不是编译型语言 零构建、零依赖、迭代快 —— 枚举算法才是真正的风险点（见 3.2 的自检提示），改起来越轻越好。 代价是每次 spawn 多约 30ms 解释器启动开销（可忽略）。 后期若要压开销：镜像里已装 g++/make、本机 gcc 13.3 亦可用，可翻成 C 二进制 —— 那是第二步，本次不做。
STEP 1读策略文件（每行一条 deny <绝对路径>），全部 realpath 规范化
STEP 2查 Landlock ABI，建 ruleset（按 ABI 取可用的最大权限集）
STEP 3枚举式授予（黑名单核心，见 3.2）
STEP 4prctl(PR_SET_NO_NEW_PRIVS, 1)
STEP 5landlock_restrict_self
STEP 6execvp(cmd) 执行目标命令

3.2 枚举式授予算法（黑名单如何实现）

Landlock 的规则只能加、不能减（多条规则取并集），因此"允许全部、只排除 X"必须靠枚举做出来：

从 "/" 开始递归：

  · 某路径 在任一 deny 之内   → 不授予，也不再向下
  · 某路径 下面没有 deny 路径  → 授予全部权限，不再向下枚举
  · 某路径 下面有 deny 路径    → 只枚举它的子项，逐个递归

细节：用 lstat，不跟随软链（避免环与无限递归）；
      /proc、/sys、/dev 下无 deny → 整片授予，不递归。
⚠️ 实现要点（三条硬性要求）
  • 必须统计并输出授予规则条数，作为第一道验收 —— 枚举一旦失效会静默整盘放行，等于没有沙盒。
  • 普通文件只能授 EXECUTE / WRITE_FILE / READ_FILE / TRUNCATE 四项。 对其使用目录级权限位会被内核判 EINVAL；真实系统根目录存在普通文件（如 /swap.img），因此必然触发。
  • 枚举时一律跳过软链。对软链调用 open(O_PATH) 会跟随到目标， 若目标正是被 deny 的目录，等于把 deny 撤销掉。跳过是安全的 —— 软链自身的可访问性由父目录的授予覆盖， 跟随后的访问按解析后的目标路径判定。
  • fail-closed 兜底：授予条数为 0、或"有 deny 却只授出 1 条"、或 deny 路径全部解析不出，均应拒绝启动。

3.3 为什么不需要枚举白名单

因为语义是"默认可访问、只减不增"：授满除 deny 之外的所有路径。所以不需要知道 Agent 需要什么 —— 系统目录、/tmp、~/.claude、node/claude 二进制、工作区，全都自动可用。

这是黑名单方案相对白名单的最大优势：杜绝了"漏了某条依赖导致 Agent 跑不起来"。

3.4 黑名单如何计算（后端，每次 spawn 现算）

以会话归属者 U 为准：

deny(U) = { 每个 V≠U 的 users.work_dir }
        ∪ { 每个 U 无写权限的 projects.bind_path }
  • 普通用户的项目因 bindPathManual 已堵掉，bind_path 必在自己的 work_dir 内 → 已被第一条覆盖
  • 第二条专门兜住管理员手动绑到外部的项目
  • 用策略文件传递而非命令行参数（列表可能很长，且避免暴露在 ps 输出里）

探测项失败含义
landlock_create_ruleset(NULL, 0, VERSION) 返回 ABI 版本内核不支持，或被安全策略挡
建 ruleset + 加一条规则 + landlock_restrict_self 全部成功权限不足或 LSM 配置问题
prctl(PR_SET_NO_NEW_PRIVS) 可置位同上
⚠️ 自检必须在子进程里执行 landlock_restrict_self 是永久自缚的。如果在 mobius 主进程里调用， 会把后端自己锁死在沙盒里。自检必须 fork 出子进程来跑。

失败回退行为：进入「不允许创建普通用户」状态 —— 注册 / 开通普通用户的入口一律拒绝， 并在管理界面与日志中给出明确原因。

建议补一条（待确认） 只禁「创建」还不够：若 Landlock 在启动之后才出问题，已存在的普通用户仍会拿到无沙盒的 Agent。 因此建议再加一道 —— spawn 时套沙盒失败就拒绝启动该 Agent（而不是降级放行）。 两条合起来才是真正闭环的 fail-closed。

9缺口与待决问题

9.1 必须正面解决（来自 §2 实测，不可延后）

unix socket 连接不受 Landlock 管辖 实测：socket 位于被显式 deny 的目录内时，open 返回 EACCES， 但 connect 成功（同一次进程内自带对照）。因此沙盒外的服务可被 Agent 指挥着干活 —— 已实测 tmux run-shell 逃逸成功，读到了被 deny 的文件。

mobius 环境下至少三个通道：tmux server（正是 Agent 的宿主）、 code-server（回环 + --auth none）、docker.sock（可达即等价 root）。

把 socket 挪到别处没用（connect 根本不看路径授权），deny 列表也拦不住。 这意味着：只给 pane 进程套 Landlock，关不住 Agent。

10为什么不用 seccomp 做自定义错误（补充说明）

内核在系统调用失败时只返回一个数字（错误码），没有任何通道能传文字：

内核返回的:   13
程序打印的:   "Permission denied"   ← 程序自己按 13 查表查出来的

因此程序打印什么，100% 由程序自己决定，内核插不上嘴。即使修改 Landlock 内核代码，能改的也只有"数字是几"。

内核唯一能带任意文字的通道是审计子系统（audit），但它通向系统审计日志而非 Agent 终端，且需要自行编译分发内核——技术上可行，实践上不可行。

真正可行的自定义话术只有两条路，而它们在容器约束下只剩一条：

在哪做手段容器内
进程内LD_PRELOAD 小动态库可用
进程外seccomp 监督进程被堵死（实测）

本次决定放弃自定义话术，因此不引入 LD_PRELOAD，保持方案最简。

A附录：驱动完整源码

即上表实测所用的 mobius-landlock（共 330 行，纯标准库， 仅用 ctypes 直调内核 syscall 444 / 445 / 446）。两个模式： --check 自检、--policy <文件> -- <命令> 应用沙盒后 exec。

#!/usr/bin/env python3
"""mobius-landlock — Landlock 黑名单启动器 / 内核能力自检

用法:
  mobius-landlock --check
        内核能力自检。在【子进程】里跑完整流程，退出码 0=可用，非 0=不可用。
        （必须子进程：landlock_restrict_self 是永久自缚，在主进程里调会锁死调用者。）

  mobius-landlock --policy FILE [--stats] -- CMD [ARG...]
        应用黑名单沙盒后 exec CMD。

策略文件格式（每行一条，'#' 起头为注释）:
  deny /abs/path

语义: 默认【全可访问】，只把 deny 路径及其子树排除。
实现: Landlock 规则只增不减（并集），故用【枚举】表达"除 X 外全部"：
      从 / 起，某目录下无 deny 则整片授予、不再下探；有 deny 才逐子项递归。
"""
import ctypes
import ctypes.util
import errno
import os
import shutil
import stat
import sys
import tempfile

# ---- 内核接口常量 ----
SYS_CREATE_RULESET, SYS_ADD_RULE, SYS_RESTRICT_SELF = 444, 445, 446
CREATE_RULESET_VERSION = 1
RULE_PATH_BENEATH = 1
PR_SET_NO_NEW_PRIVS = 38

R = {  # Landlock 文件系统权限位
    "EXECUTE": 1 << 0, "WRITE_FILE": 1 << 1, "READ_FILE": 1 << 2,
    "READ_DIR": 1 << 3, "REMOVE_DIR": 1 << 4, "REMOVE_FILE": 1 << 5,
    "MAKE_CHAR": 1 << 6, "MAKE_DIR": 1 << 7, "MAKE_REG": 1 << 8,
    "MAKE_SOCK": 1 << 9, "MAKE_FIFO": 1 << 10, "MAKE_BLOCK": 1 << 11,
    "MAKE_SYM": 1 << 12, "REFER": 1 << 13, "TRUNCATE": 1 << 14,
    "IOCTL_DEV": 1 << 15,
}

libc = ctypes.CDLL(None, use_errno=True)


class RulesetAttr(ctypes.Structure):
    _fields_ = [("handled_access_fs", ctypes.c_uint64),
                ("handled_access_net", ctypes.c_uint64),
                ("scoped", ctypes.c_uint64)]


class PathBeneathAttr(ctypes.Structure):
    _fields_ = [("allowed_access", ctypes.c_uint64),
                ("parent_fd", ctypes.c_int32),
                ("reserved", ctypes.c_uint32)]


def abi_version():
    """返回内核 Landlock ABI 版本；不可用时抛 OSError。"""
    r = libc.syscall(SYS_CREATE_RULESET, None, 0, CREATE_RULESET_VERSION)
    if r < 0:
        e = ctypes.get_errno()
        raise OSError(e, f"landlock_create_ruleset(VERSION): {os.strerror(e)}")
    return r


def fs_mask_for(abi):
    """按 ABI 取可用的最大权限位集合（位越界会导致 EINVAL）。"""
    mask = (1 << 13) - 1                      # ABI1: 位 0..12
    if abi >= 2:
        mask |= R["REFER"]
    if abi >= 3:
        mask |= R["TRUNCATE"]
    if abi >= 5:
        mask |= R["IOCTL_DEV"]
    return mask


def mask_for(abi, is_dir):
    """普通文件只接受 EXECUTE/WRITE_FILE/READ_FILE/TRUNCATE（内核 landlock.h 明载），
    对文件用目录级权限位会被内核判 EINVAL。"""
    m = fs_mask_for(abi)
    if is_dir:
        return m
    file_ok = R["EXECUTE"] | R["WRITE_FILE"] | R["READ_FILE"] | R["TRUNCATE"]
    return m & file_ok


def ruleset_size_for(abi):
    """struct 大小必须匹配内核支持的最大值：传大了 E2BIG，传小了丢字段。"""
    if abi <= 3:
        return 8                              # 仅 handled_access_fs
    if abi <= 5:
        return 16                             # + handled_access_net
    return 24                                 # + scoped


class DenySpec:
    """解析后的策略：规范化的 deny 路径集合。"""

    def __init__(self, paths):
        self.raw = list(paths)
        self.missing = []
        self.resolved = []
        for p in self.raw:
            ap = os.path.abspath(p)
            if not os.path.exists(ap):
                self.missing.append(ap)
                continue
            self.resolved.append(os.path.realpath(ap))
        # 去掉被其它 deny 覆盖的路径（冗余规则）
        dedup = []
        for p in sorted(set(self.resolved), key=len):
            if not any(p == q or p.startswith(q + os.sep) for q in dedup):
                dedup.append(p)
        self.paths = dedup


def parse_policy(path):
    paths = []
    with open(path, "r", encoding="utf-8") as fh:
        for line in fh:
            line = line.strip()
            if not line or line.startswith("#"):
                continue
            if not line.startswith("deny "):
                raise ValueError(f"策略文件格式错误（应为 'deny <路径>'）: {line!r}")
            paths.append(line[5:].strip())
    return DenySpec(paths)


def build_ruleset(spec, log):
    """建 ruleset 并按枚举法授予。返回 (ruleset_fd, 授予条数, 统计)。"""
    abi = abi_version()
    size = ruleset_size_for(abi)
    attr = RulesetAttr(handled_access_fs=fs_mask_for(abi))
    fd = libc.syscall(SYS_CREATE_RULESET, ctypes.byref(attr), size, 0)
    if fd < 0:
        e = ctypes.get_errno()
        raise OSError(e, f"landlock_create_ruleset: {os.strerror(e)}")

    stats = {"granted": 0, "skipped_unlistable": 0, "skipped_symlink": 0,
             "deny_roots": len(spec.paths)}

    def inside(p, root):
        # root 为 "/" 时特判：一切都在它里面（否则 "/"+sep 会变成 "//"）
        if root == os.sep:
            return True
        return p == root or p.startswith(root + os.sep)

    def has_deny_below(p):
        return any(inside(d, p) and d != p for d in spec.paths)

    def grant(p, is_dir):
        try:
            pfd = os.open(p, os.O_PATH | os.O_CLOEXEC)
        except OSError:
            stats["skipped_unlistable"] += 1
            return
        try:
            pb = PathBeneathAttr(allowed_access=mask_for(abi, is_dir),
                                 parent_fd=pfd, reserved=0)
            r = libc.syscall(SYS_ADD_RULE, fd, RULE_PATH_BENEATH,
                             ctypes.byref(pb), 0)
            if r < 0:
                e = ctypes.get_errno()
                raise OSError(e, f"landlock_add_rule {p}: {os.strerror(e)}")
        finally:
            os.close(pfd)
        stats["granted"] += 1

    def walk(p):
        """p 已确认为目录"""
        if any(inside(p, d) for d in spec.paths):
            return                                    # 在 deny 之内：不授予
        if not has_deny_below(p):
            grant(p, True)                            # 下面无 deny：整片授予
            return
        try:
            entries = os.listdir(p)
        except OSError as e:
            # 列不出来就无法判断下面有没有 deny → 不授予（fail-closed）并记数
            stats["skipped_unlistable"] += 1
            log(f"[warn] 无法列目录，按 fail-closed 处理（不授予）: {p} ({e})")
            return
        for name in entries:
            c = os.path.join(p, name)
            try:
                st = os.lstat(c)
            except OSError:
                continue
            if stat.S_ISLNK(st.st_mode):
                # 软链一律不授予：O_PATH 打开会跟随到目标，若目标是 deny 目录
                # 就等于把 deny 撤销了。不授予也安全 —— 软链自身的可访问性由
                # 其父目录的授予覆盖，而跟随后的访问按【解析后的目标】判定。
                stats["skipped_symlink"] += 1
                continue
            if stat.S_ISDIR(st.st_mode):
                walk(c)
            else:
                grant(c, False)                       # 普通文件用文件级权限位

    walk(os.sep)
    return fd, stats, abi


def apply(spec, log):
    fd, stats, abi = build_ruleset(spec, log)
    if libc.prctl(PR_SET_NO_NEW_PRIVS, 1, 0, 0, 0) != 0:
        e = ctypes.get_errno()
        raise OSError(e, f"prctl(PR_SET_NO_NEW_PRIVS): {os.strerror(e)}")
    if libc.syscall(SYS_RESTRICT_SELF, fd, 0) != 0:
        e = ctypes.get_errno()
        raise OSError(e, f"landlock_restrict_self: {os.strerror(e)}")
    os.close(fd)
    return stats, abi


def do_check():
    """在子进程里跑完整流程验证内核能力。返回 0/非 0。"""
    pid = os.fork()
    if pid == 0:                                      # 子进程：可安全自缚
        # os._exit 不刷 stdio 缓冲，必须直接用 os.write 落盘
        def emit(s, fd=1):
            os.write(fd, s.encode("utf-8", "replace"))

        try:
            abi = abi_version()
            if abi < 1:
                emit("FAIL abi<1\n", 2)
                os._exit(11)
            # 用一个真实存在的临时目录当 deny，让枚举真正走一遍递归分支
            probe_dir = tempfile.mkdtemp(prefix="mobius-landlock-probe-")
            spec = DenySpec([probe_dir])
            fd, stats, _ = build_ruleset(spec, lambda m: None)
            shutil.rmtree(probe_dir, ignore_errors=True)
            if libc.prctl(PR_SET_NO_NEW_PRIVS, 1, 0, 0, 0) != 0:
                emit("FAIL prctl(PR_SET_NO_NEW_PRIVS)\n", 2)
                os._exit(12)
            if libc.syscall(SYS_RESTRICT_SELF, fd, 0) != 0:
                emit("FAIL landlock_restrict_self\n", 2)
                os._exit(13)
            os.close(fd)
            if stats["granted"] <= 0:
                emit("FAIL granted=0（等于没有沙盒）\n", 2)
                os._exit(14)
            emit(f"OK landlock abi=v{abi} granted={stats['granted']}\n")
            os._exit(0)
        except OSError as e:
            emit(f"FAIL {e}\n", 2)
            os._exit(20)
        except Exception as e:                        # noqa: BLE001
            emit(f"FAIL {type(e).__name__}: {e}\n", 2)
            os._exit(21)
    _, status = os.waitpid(pid, 0)
    return os.waitstatus_to_exitcode(status)


def main(argv):
    if len(argv) < 2:
        print(__doc__, file=sys.stderr)
        return 2

    if argv[1] == "--check":
        return do_check()

    if argv[1] != "--policy":
        print(f"未知参数: {argv[1]}", file=sys.stderr)
        return 2

    policy, show_stats, cmd = None, False, []
    i = 2
    while i < len(argv):
        a = argv[i]
        if a == "--":
            cmd = argv[i + 1:]
            break
        if a == "--stats":
            show_stats = True
        elif policy is None:
            policy = a
        else:
            print(f"多余参数: {a}", file=sys.stderr)
            return 2
        i += 1

    if not policy or not cmd:
        print("用法: mobius-landlock --policy FILE [--stats] -- CMD ...",
              file=sys.stderr)
        return 2

    def log(m):
        print(m, file=sys.stderr)

    try:
        spec = parse_policy(policy)
        for m in spec.missing:
            log(f"[warn] deny 路径不存在，已跳过: {m}")
        stats, abi = apply(spec, log)
    except Exception as e:                            # noqa: BLE001
        log(f"[fatal] 沙盒应用失败: {type(e).__name__}: {e}")
        return 1

    if stats["granted"] <= 0:
        # 授了 0 条规则 = 整盘放行，等于没有沙盒 → 拒绝执行（fail-closed）
        log("[fatal] 未授予任何规则，判定为沙盒失效，拒绝启动")
        return 1
    if spec.paths and stats["granted"] == 1:
        # 有 deny 却只授出 1 条 = 根目录被误判为"下面没有 deny" → 整盘放行。
        # 这是枚举失效的典型签名（历史 bug："/" + os.sep 变 "//"），必须拦下。
        log("[fatal] 有 deny 路径却只授予 1 条规则，判定为枚举失效（疑似整盘放行），拒绝启动")
        return 1
    if spec.raw and not spec.paths:
        # 策略里写了 deny，却一条都解析不出（路径全不存在）→ 实际等于无限制。
        # 这属于 fail-open，不能放行：上游给错了路径就不该静默降级。
        log(f"[fatal] 策略含 {len(spec.raw)} 条 deny 但全部无法解析（路径不存在），"
            f"拒绝启动（fail-closed）")
        return 1
    if show_stats:
        log(f"[mobius-landlock] abi=v{abi} deny={stats['deny_roots']} "
            f"granted={stats['granted']} symlink_skipped={stats['skipped_symlink']} "
            f"unlistable={stats['skipped_unlistable']}")

    os.execvp(cmd[0], cmd)
    return 127                                        # 不可达


if __name__ == "__main__":
    sys.exit(main(sys.argv))
